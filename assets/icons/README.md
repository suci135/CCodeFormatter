# UI 图标资源

应用图标 `app-icon.svg` 使用代码括号、格式化斜线和对齐线组合而成，作为本地项目图形资源使用。

本目录中的两个 SVG 来自阿里巴巴官方 `alibaba-sa/cloud-icons` 开源仓库，
用于本地拖入区和文件选择按钮的视觉提示：

- `alibaba-file-cloud.svg`：文件/对象存储语义
- `alibaba-code-shell.svg`：代码/命令行语义（历史资源，保留备用）

主题和文件操作图标来自 Tabler Icons：

- `tabler-moon.svg` / `tabler-sun.svg`：主题切换
- `tabler-file-plus.svg`：选择文件
- `tabler-file-code.svg`：代码文件列表

来源：https://github.com/alibaba-sa/cloud-icons
来源：https://github.com/tabler/tabler-icons
